# sun-panel-warehouse-liteyais-daily-movie

每日电影微应用海报仓库（Sun-Panel V2 微应用「每日电影」专用）

- `posters/`：582 张豆瓣高分影片海报（p000.webp ~ p599.webp，跳过失效序号），经 jsDelivr 由微应用按需下载
- `posters.zip`：全部海报打包（约 12MB）。NAS 用户可下载后解压到微应用安装目录，海报即走本地文件、零网络
- jsDelivr 地址：`https://fastly.jsdelivr.net/gh/liteyais/sun-panel-warehouse-liteyais-daily-movie@main/posters/pNNN.webp`
